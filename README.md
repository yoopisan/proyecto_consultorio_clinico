# proyecto_consultorio_clinico
# 1. Instalación y configuración.
### Requisitos
#
# - Java JDK 11
# - IntelliJ IDEA
# - Git
# - Maven
### Instalación
#
# 1. Clonar el repositorio.
# 2. Abrir el proyecto en IntelliJ IDEA.
# 3. Verificar que Java 11 esté configurado.
# 4. Ejecutar Maven para construir el proyecto.
### Generar el JAR
#
# Ejecutar:
#
# mvn clean package
#
# El archivo JAR se encontrará dentro de la carpeta target.
# 2. Uso del programa.
#
# El programa permite:
#
# - Registrar doctores.
# - Registrar pacientes.
# - Crear citas.
# - Consultar doctores.
# - Consultar pacientes.
# - Consultar citas.
#
# La información se almacena localmente en archivos CSV dentro
# de la carpeta db.
#
# Los archivos de información son generados automáticamente
# si no existen.
